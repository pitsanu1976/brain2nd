# Daily Workflow

capture -> inbox triage -> daily note -> project (ตาม CODE ใน [[Second Brain]])

## 1. Capture (ตลอดวัน)

จดทุกอย่างลง `01 Inbox` (new notes ไปที่นี่อัตโนมัติ) หรือ append ใน `Inbox.md` ไม่ต้องจัดหมวด ไม่ต้องตั้งชื่อสวย

## 2. Inbox triage (เช้า หรือท้ายวัน 10 นาที)

| รายการ | ปลายทาง |
|---|---|
| งานที่มีเป้าหมาย | `10 Projects` |
| ความรับผิดชอบต่อเนื่อง | `20 Areas` |
| อ้างอิง/บทความ | `30 Resources` หรือ `50 Wiki/raw/` ถ้าจะ ingest |
| ไม่ใช้แล้ว | `40 Archive` |

## 3. Daily note

เปิด daily note ของวัน (`02 Daily/YYYY-MM-DD`) จาก template: เป้าหมายวันนี้, log งาน, ข้อสังเกต, link ไป Project/Meeting

## 4. Project

บันทึกความคืบหน้าใน Project note (template [[Templates Reference]]) ลิงก์ไปหน้า wiki ที่ใช้ เมื่อโปรเจกต์จบ distill บทเรียนเป็นหน้า wiki แล้วย้ายไป `40 Archive`

## 5. ทบทวนรายสัปดาห์

ล้าง Inbox, ตรวจ Project ที่ค้าง, ส่ง source สำคัญให้ Claude Code ingest ([[Using Claude Code on a Vault]])
