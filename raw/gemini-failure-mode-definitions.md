## ผลการตรวจทานกับ ISO 14224 (ทำ 2026-11-10)

| # | ข้อความใน clipping | สถานะ | ที่ถูกต้อง |

| 1 | ตารางแรกมี 16 แถว (รวม OTH/UNK) ตารางเพิ่มเติม 2 แถว = 18 โหมด | **ไม่ครบ** | ISO Table B.15 มี **62 รหัส** ทุก equipment class; สำหรับ compressor (CO) Table B.6 ใช้ **20 รหัส** |

| 6 | ตัวอย่าง ELU = "น้ำมันไฮดรอลิกหยดรั่วจากซีลปั๊ม" | **กำกวม** | ขึ้นกับ boundary: ของเหลว utility ที่อยู่ภายในอุปกรณ์ (น้ำมันหล่อลื่น/ไฮดรอลิกของปั๊มเอง) มักบันทึกเป็น ELU หรือ SER; ELP สงวนไว้สำหรับ process medium |

**สรุปที่ใช้ได้:** เกณฑ์ 3 ข้อของ clipping (ดูอาการที่สังเกตได้ / ดู equipment boundary / แยก mode–mechanism–cause) ถูกต้องและตรงกับ [[Failure Mode]] และ [[Failure Hierarchy]] — ส่วนที่ต้องเพิ่มเองคือ PLU, การแยก STP/UST และการไม่เรียกรายการนี้ว่า "ทั้งหมด"

**Gemini**

ในระบบวิศวกรรมความน่าเชื่อถือ (Reliability Engineering) **OREDA (Offshore and Onshore Reliability Data)** ซึ่งสอดคล้องกับมาตรฐานสากล **ISO 14224** ได้กำหนดการจำแนกประเภทโหมดความเสียหาย (**Failure Mode**) ไว้เพื่อให้องค์กรสามารถเก็บข้อมูล บันทึกประวัติการซ่อมบำรุง และนำไปวิเคราะห์ได้อย่างเป็นระบบ

### หลักเกณฑ์การเลือกใช้งาน Failure Mode (Selection Criteria)

การเลือกใช้รหัส Failure Mode ให้ถูกต้อง มีหลักการพิจารณาดังนี้:

1. **พิจารณาจาก "อาการที่สังเกตเห็น" (The Observed Effect):** Failure Mode คือสิ่งที่คุณเห็นหรือตรวจพบ ไม่ใช่สาเหตุที่แท้จริง (เช่น ปั๊มน้ำมันรั่ว อาการที่เห็นคือ Leakage ไม่ใช่วาล์วเสื่อมสภาพ)
2. **ขอบเขตของอุปกรณ์ (Equipment Boundary):** วิเคราะห์ผลกระทบที่เกิดขึ้นภายในขอบเขตของอุปกรณ์ชิ้นนั้นๆ ตามมาตรฐาน
3. **แยกแยะให้ชัดเจนระหว่าง 3 เลเยอร์:**
	- **Failure Mode (อาการ):** มันแสดงอาการอย่างไร เช่น *External Leakage (ELP)*
		- **Failure Mechanism (กลไกทางกายภาพ):** เกิดจากอะไร เช่น *Corrosion หรือ Wear*
		- **Failure Cause (สาเหตุรากเหง้า):** ต้นตอมาจากไหน เช่น *Improper lubrication หรือ Installation error*

### รายการ Failure Modes หลักตามมาตรฐาน OREDA / ISO 14224 Optimal.world

ตารางด้านล่างนี้รวบรวมรหัส Failure Mode ที่ใช้งานบ่อย พร้อมคำอธิบายและตัวอย่างประกอบ:

| Code | Failure Mode (ชื่อโหมด) | ความหมายและลักษณะอาการ | ตัวอย่างการใช้งานจริง |
| --- | --- | --- | --- |
| **AIR** | **Abnormal Instrument Reading** | ค่าที่อ่านได้จากเครื่องมือวัดมีความผิดปกติ เกินจริง หรือค่าค้าง | เกจวัดความดัน (Pressure Gauge) ค้างที่ค่าสูงสุดตลอดเวลา แม้ระบบจะหยุดทำงานแล้ว |
| **BRD** | **Breakdown** | การพังเสียหายอย่างรุนแรงจนอุปกรณ์หยุดทำงานกะทันหันและเสียหายหนัก | เพลาของคอมเพรสเซอร์หักคาสนาม หรือใบพัดกังหันแตกละเอียด |
| **ELP** | **External leakage - Process medium** | การรั่วไหลออกสู่ภายนอกของสารในกระบวนการผลิต (ไฮโดรคาร์บอน, ก๊าซ, น้ำมันดิบ) | น้ำมันดิบรั่วซึมผ่านหน้าแปลน (Flange) ของท่อส่งในแท่นขุดเจาะ |
| **ELU** | **External leakage - Utility medium** | การรั่วไหลออกสู่ภายนอกของสารระบบสาธารณูปโภค | น้ำหล่อเย็น (Cooling water) หรือน้ำมันไฮดรอลิกหยดรั่วจากซีลปั๊ม |
| **ERO** | **Erratic output** | สัญญาณหรือค่าเอาต์พุตมีความผันผวน ไม่เสถียร แกว่งไปมา | เครื่องส่งสัญญาณกระแสไฟฟ้า (Transmitter) ส่งค่ากระแสแกว่งขึ้นลงตลอดเวลาโดยที่กระบวนการนิ่ง |
| **FTS** | **Fail to start on demand** | ไม่สามารถเริ่มทำงานได้เมื่อมีคำสั่งหรือมีความต้องการใช้งาน | เครื่องกำเนิดไฟฟ้าฉุกเฉิน (Emergency Generator) ไม่ยอมติดเครื่องเมื่อระบบไฟหลักดับ |
| **HIO** | **High output** | ค่าเอาต์พุตหรือประสิทธิภาพสูงเกินกว่าค่ากำหนดหรือพิกัดสูงสุด | วาล์วควบคุมเปิดกว้างเกินไป ทำให้ความดันปลายทางสูงเกินพิกัดความปลอดภัย |
| **INL** | **Internal leakage** | การรั่วไหลภายในระบบ ผ่านอุปกรณ์กั้น เช่น บ่าวาล์ว หรือซีลภายใน | วาล์วปิดสนิทแล้ว แต่ยังมีก๊าซรั่วไหลผ่านบ่าวาล์วข้ามไปยังอีกฝั่งหนึ่ง |
| **LOO** | **Low output** | ค่าเอาต์พุตหรือสมรรถนะต่ำกว่าเกณฑ์มาตรฐาน | ปั๊มน้ำสามารถส่งอัตราการไหล (Flow rate) ได้น้อยกว่าสเปคที่กำหนด |
| **NOI** | **Noise** | เกิดเสียงดังผิดปกติระหว่างเครื่องจักรกำลังทำงาน | ตลับลูกปืน (Bearing) ส่งเสียงดังหวีดหวิวหรือเสียงกระแทกขณะหมุน |
| **OHE** | **Overheating** | อุณหภูมิของอุปกรณ์สูงเกินกว่าขีดจำกัดความปลอดภัย | มอเตอร์ไฟฟ้ามีอุณหภูมิผิวตัวเรือนสูงขึ้นจนระบบทริป (Trip) |
| **STD** | **Structural deficiency** | ความบกพร่องทางโครงสร้าง เช่น รอยร้าว การสึกกร่อน หรือการเสียรูป | พบรอยร้าวที่ฐานรองรับถังแรงดัน (Pressure Vessel Skirt) เนื่องจากการกัดกร่อน |
| **STP** | **Failure to stop on demand / Spurious stop** | อุปกรณ์ไม่ยอมหยุดทำงานตามคำสั่ง หรือหยุดทำงานเองโดยพลการ (Spurious Trip) | วาล์วตัดอัตโนมัติไม่ยอมปิดเมื่อกดปุ่มสั่งหยุด หรือปั๊มตัดการทำงานเองโดยไม่มีสาเหตุ |
| **VIB** | **Vibration** | การสั่นสะเทือนรุนแรงเกินกว่าค่าเกณฑ์มาตรฐาน (Alarm/Trip limit) | มอเตอร์และปั๊มเกิดการสั่นสะเทือนสูงผิดปกติเนื่องจากข้อต่อเยื้องศูนย์ (Misalignment) |
| **SER** | **Minor in-service problems** | ปัญหาเล็กน้อยระหว่างปฏิบัติงานที่ไม่ถึงขั้นทำให้ระบบหยุดทำงานทันที | น็อตยึดฝาครอบหลวม หรือมีคราบสกปรกภายนอกอุปกรณ์ |
| **OTH / UNK** | **Other / Unknown** | อาการความเสียหายอื่นๆ ที่ไม่อยู่ในข่ายข้างต้น หรือมีข้อมูลไม่เพียงพอที่จะระบุได้ | ไม่สามารถสรุปอาการได้แน่ชัดเนื่องจากข้อมูลในใบแจ้งซ่อม (Work Order) ไม่สมบูรณ์ |

### รายการ Failure Mode เพิ่มเติม

| Code | Failure Mode (ชื่อโหมด) | ความหมายและลักษณะอาการ | ตัวอย่างการใช้งานจริง |
| --- | --- | --- | --- |
| **PDE** | **Parameter deviation** | ค่าพารามิเตอร์ในกระบวนการ (เช่น อุณหภูมิ ความดัน อัตราการไหล หรือระดับของเหลว) เบี่ยงเบนไปจากค่าที่ตั้งไว้ (Setpoint) แต่ยังไม่ถึงขั้นหลุดออกนอกขีดจำกัดความปลอดภัยจนทริป | อุณหภูมิของน้ำมันหล่อลื่นในชุดเกียร์สูงขึ้นกว่าปกติ 10 องศาเซลเซียสอย่างต่อเนื่อง แต่ยังไม่ถึงจุดที่ระบบตั้ง Alarm/Trip |
| **UST** | **Spurious stop / Unwanted stop** | เครื่องจักรหรือระบบหยุดทำงานเองโดยพลการ โดยที่ไม่มีคำสั่งจากผู้ใช้งานและไม่มีภาวะความผิดปกติที่แท้จริงในระบบ (False Trip) | คอมเพรสเซอร์ก๊าซตัดการทำงาน (Trip) เองกะทันหัน ทั้งที่ค่าความดันและอุณหภูมิอยู่ในเกณฑ์ปกติทุกประการ (มักเกิดจากความผิดพลาดของสัญญาณเครื่องมือวัดหรือระบบคอนโทรล) |
