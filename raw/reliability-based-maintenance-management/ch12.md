## การวิเคราะห์โอกาส (book p.365)
- ความน่าจะเป็น (probability) = โอกาสเกิดเหตุการณ์ในแต่ละช่วง; ความน่าจะเป็นสะสม (cumulative probability) = โอกาสสะสมถึงค่าหนึ่ง
- ตัวอย่าง: เตรียมอาหาร 100 ที่ พอเพียงแค่ 5% ของครั้ง; 200 ที่ -> 30%; 300 ที่ -> 70%; 400 ที่ -> 100%. ช่วง 251-300 คนมีโอกาส 25%

## การวิเคราะห์ค่ากลาง (book p.365-367)
- ค่ากลางเป็นตัวแทนชุดข้อมูล มี 3 แบบ
- Mean (ค่าเฉลี่ยเลขคณิต) = sum(Xi)/N; ตัวอย่างได้ 241.3 คน
- Median = ค่าตำแหน่ง (N+1)/2 ของข้อมูลที่เรียงแล้ว; ตัวอย่างตำแหน่ง 10.5 -> (252+253)/2 = 252.5
- Mode = ค่าที่ความถี่สูงสุด; ตัวอย่างช่วง 251-350 (ประมาณ 300)
- การจัดข้อมูล (distribution) สำคัญเพราะส่งผลต่อผลวิเคราะห์ ในงานวิศวกรรมนิยมใช้ Statistic Distribution Function (เช่น Normal, Exponential, Poisson) ซึ่งหา cumulative probability, โอกาส, failure rate, ค่ากลาง ได้จากสมการ

## การใช้งานสถิติสำหรับงานซ่อมบำรุง (book p.367-370)
- งานซ่อมบำรุงสนใจโอกาสและความเสี่ยงที่เครื่องเสีย -> ต้องเข้าใจ probability ก่อน (ตัวอย่างลูกเต๋าออกหน้า 4 = 1/6)
- รูป 12.6: กราฟระฆังคว่ำ พื้นที่ใต้กราฟระหว่าง a ถึง b = โอกาสเสียในช่วง a-b; สมการนี้คือ Probability Density Function (pdf), f(t)
- ความน่าจะเป็นอยู่ในช่วง 0-1; พื้นที่ใต้กราฟรวม = 1 (100%): integral f(t)dt = 1 (รูป 12.7)
- ความน่าจะเป็นสะสม = Cumulative Distribution Function (cdf, F(t)) = integral จาก 0 ถึง t ของ f(s)ds (ตัวอย่างลูกเต๋าหน้า 1-4 = 4/6 = 2/3). รูป 12.8 แสดงความสัมพันธ์ pdf กับ cdf (cdf เป็นรูปตัว S เข้าใกล้ 1)
- รูป 12.9: ที่เวลา a พื้นที่ซ้าย = Probability of Failure/Unreliability; พื้นที่ขวา = Probability of Survive = Reliability
- สูตรหลัก:
  - F(t) = Q(t) = integral_0^t f(s)ds (unreliability)
  - Q(t) + R(t) = 1; R(t) = 1 - Q(t) = integral_t^inf f(s)ds
  - f(t) = -dR(t)/dt (ในหนังสือเขียน d(R(t))/dt ไม่มีเครื่องหมายลบ [ตามที่พิมพ์])
  - Failure rate lambda(t) = f(t) / (1 - integral_0^t f(s)ds) = f(t)/R(t) (hazard rate)

## สมการสถิติ (book p.371)
- 2 ประเภท:
  1. Discrete Function: วิเคราะห์ได้เฉพาะค่าจำนวนเต็ม (0,1,2,...) เช่น Poisson, Binomial, Geometric, Hypergeometric; ใช้ในงานอะไหล่ (การเบิก, ปริมาณสำรองคลัง, จำนวนที่ใช้)
  2. Continuous Function: วิเคราะห์ได้ตลอดช่วง เช่น Normal, Exponential, Weibull, Log Normal; ใช้วิเคราะห์โอกาสเสียที่เวลาต่าง ๆ และช่วงเวลา Planned Maintenance
- เกณฑ์เลือกสมการ 3 ข้อ: (1) ลักษณะการวิเคราะห์ (ต่อเนื่อง/ช่วง) (2) สมมติฐานของสมการตรงกับงานหรือไม่ (3) ข้อมูลเหมาะกับสมการหรือไม่ (ตรวจหลังหา parameter)

## สมการสถิติแบบต่อเนื่อง: Normal Distribution (book p.374-376)
- สมมติฐาน: เหตุการณ์กระจุกที่ค่ากลาง (mean) และกระจายสมมาตรซ้าย-ขวา (กราฟระฆัง, รูป 12.10)
- pdf = [1/(sigma * sqrt(2 pi))] * exp(-1/2 * ((x - mu)/sigma)^2)
- Parameters: mu (mean), sigma (standard deviation)
- ตัวอย่างจริง: เวลาเดินทาง กทม.-ภูเก็ต ~10 ชม. คลาดเคลื่อน 1-2 ชม.; ในงานซ่อม: ชิ้นส่วนที่เสียจากหมดอายุการใช้งาน (wear-out) ประมาณอายุได้
- การประมาณ parameter: N น้อย: mu = sum(Xi)/N, sigma = sqrt(sum(Xi - mu)^2 / N); N มาก (>20): หนังสือใช้ N-1 ในตัวหาร [ตามที่พิมพ์ -- ธรรมเนียมสถิติมักตรงข้าม (N-1 สำหรับตัวอย่างน้อย) และตัวอย่างถัดไปใช้ N-1 ทั้งที่ N = 9]
- ตัวอย่าง: เครื่องจักรเสีย 9 ครั้ง อายุเดินเครื่อง (วัน): 315, 220, 402, 307, 163, 280, 485, 293, 190 -> mu = 295, sigma = 101.486 (คำนวณด้วยตัวหาร N-1)
- รูป 12.11 = pdf (ยอดกราฟประมาณ 0.39-0.40% ต่อวัน ที่ ~295 วัน); รูป 12.12 = cdf (S-curve)
- ผล: โอกาสเสียภายใน 120 วัน = 4.23%; 180 วัน = 12.86%; 365 วัน = 75.48%
- วางแผน PM ลดโอกาสเสียต่อปี (เปรียบเทียบความถี่ PM):
  - ทำ PM ปีละ 3 ครั้ง (ทุก 120 วัน): 1 - (1-0.0423)^3 = 12.17%
  - ปีละ 2 ครั้ง (ทุก 180 วัน): 1 - (1-0.1286)^2 = 24.06%
  - ปีละครั้ง (365 วัน): 75.48%
- (ข้อสังเกต: เป็นการประมาณแบบ shortcut ที่สมมติว่า PM รีเซ็ตเครื่องกลับสภาพ as-good-as-new)

## Exponential Distribution (book p.376-378)
- สมมติฐาน: เหตุการณ์มีโอกาสเกิดเท่ากันตลอดเวลาแบบสุ่ม (constant failure rate; memoryless)
- pdf = lambda * e^(-lambda x); cdf = 1 - e^(-lambda x)
- lambda = 1 / (mean ของ sum(Xi)/N) = 1/MTTF
- ตัวอย่างจริง: อุบัติเหตุ; ในงานซ่อม: การเสียที่มาจากการใช้งานผิดวิธี (ชิ้นส่วนเสียก่อน/หลังเวลาที่ควร) หรืออุปกรณ์ไฟฟ้าที่คาดเดาอายุไม่ได้
- ตัวอย่าง: หลอดไฟอายุ 150, 700, 3120, 1200, 2560 ชม. -> mean 1546 ชม., lambda = 1/1546 = 0.00064683
  - pdf ที่ 2000 ชม. = 0.0177% (ความหนาแน่นที่จุดเดียว)
  - cdf ที่ 2000 ชม. = 72.57% (โอกาสเสียภายใน 2000 ชม.)
  - cdf ที่ 1000 ชม. = 47.63%; ที่ 500 ชม. = 27.63%
  - เปลี่ยนหลอดทุก 1000 ชม. (2 รอบ) หรือทุก 500 ชม. (4 รอบ): 1 - (1-0.4763)^2 = 1 - (1-0.2763)^4 = 72.57% เท่าเดิม
- ข้อสรุปสำคัญ: สำหรับการเสียแบบ Exponential การเปลี่ยนอะไหล่ตามแผน/Schedule Overhaul ไม่ลดโอกาสเสีย เพราะสาเหตุส่วนใหญ่คือ human error ไม่ใช่การหมดอายุของชิ้นส่วน

## Weibull Distribution (book p.378-379)
- Weibull ปรับรูปร่างได้ตาม parameter จึงเลียนแบบ distribution อื่นได้เกือบหมด นิยมในอุตสาหกรรม
- pdf: f(t) = (beta/eta) * ((t - gamma)/eta)^(beta-1) * exp(-((t - gamma)/eta)^beta)
- 3 parameters: beta = shape (รูปร่าง), eta = scale (ขนาด; characteristic life), gamma = location (ตำแหน่ง; failure-free time)
- Hazard: lambda(T) = f(T)/R(T) = (beta/eta) * ((T - gamma)/eta)^(beta-1)
- รูป 12.13: pdf และ failure rate ของ beta = 0.5, 1, 3
  - beta < 1: failure rate ลดลงตามเวลา (infant mortality)
  - beta = 1: failure rate คงที่ (random = Exponential)
  - beta > 1 (เช่น 3): failure rate เพิ่มขึ้น (wear-out)
  - ผู้เขียนกล่าวว่าอัตราการเสียมี 6 รูปแบบ (เทียบกับ bathtub / 6 failure patterns ของ RCM) ที่ Weibull แสดงแทนได้

## Estimation of Weibull Parameter (book p.379-384)
- ต้องประมาณ parameter จากประวัติ; วิธีนิยม = Probability Plot (หรือ regression)
- สมมติ gamma = 0 (เครื่องมีโอกาสเสียตั้งแต่เริ่มใช้งาน)
- cdf: F(t) = Q(T) = 1 - exp(-(T/eta)^beta)
- แปลงเป็นเส้นตรง y = a x + b (ใส่ log สองครั้ง):
  - ln(ln(1/(1 - Q(T)))) = beta ln(T) - beta ln(eta)
  - y = ln(ln(1/(1-Q))), x = ln(T), slope a = beta, intercept b = -beta ln(eta)
- พล็อตบนกระดาษ Double Log Reciprocal Scale (Weibull paper) -> beta = ความชัน
- เมื่อ T = eta: Q = 1 - e^-1 = 63.2% ไม่ว่า beta เท่าใด -> eta = จุดตัดแกน X ที่ Q = 63.2%
- รูป 12.14: Weibull probability plot ตัวอย่าง (T = 8500 Q=15.9; 11000 Q=38.6; 12000 Q=61.3; 16000 Q=84.0) ได้ beta ~3.7, eta ~13000
- แกน X = Time to Failure เรียงน้อย->มาก; แกน Y = โอกาสเสียประมาณด้วย Median Rank: MR = (j - 0.3)/(N + 0.4) (j = ลำดับการเสียจากน้อยไปมาก, N = จำนวนข้อมูลทั้งหมด; Benard approximation)
- ไม่มีกระดาษ Weibull -> ใช้ Linear Regression ใน Excel
  - Y Regression: ลดระยะห่างแนวแกน Y; X Regression: ลดระยะห่างแนวแกน X (รูป 12.15)
  - Y Regression: a = (sum(y)*sum(x) - N*sum(xy)) / ((sum x)^2 - N*sum(x^2))
  - X Regression: a = ((sum y)^2 - N*sum(y^2)) / (sum(x)*sum(y) - N*sum(xy))
  - eta = exp(-(sum(y) - a*sum(x)) / (N*a))
  - beta = a (ความชัน)

## Data and Data Type / Data Classification (book p.384-387)
- บางครั้งไม่ทราบ time to fail แน่นอน (เปลี่ยนก่อนเสียตาม PM, หรือเสียนานแล้วเพิ่งตรวจพบ) -> ต้องจำแนกประเภทข้อมูล 4 ชนิด:
  1. Complete Data (F): ทราบเวลาเสียแน่นอน
  2. Right Censored ("Right Sensor") Data (S, suspension): เคยใช้งานมาระดับหนึ่งและยังใช้ต่อได้/ถูกเปลี่ยนก่อนเสีย (เช่น PM แบบ Part Replacement ตามช่วงเวลา)
  3. Interval Censored Data: ไม่ทราบเวลาเสียแน่ชัด แต่มีการตรวจเช็คจึงทราบช่วงที่เสีย
  4. Left Censored Data: ทราบเมื่อใช้งานไม่ได้แล้วแต่ไม่รู้เวลาที่เสีย (เช่น อุปกรณ์ที่เสียแบบไม่แสดง/hidden failure เช่น fuse, safety device)
- การประมาณปกติ: Complete Data ใช้พล็อต; Interval และ Left ใช้ค่ากลางของช่วง; Right Censored พล็อตเองไม่ได้ แต่ช่วยเพิ่มความแม่นยำ (ผ่านการปรับตำแหน่ง rank)

### ตัวอย่าง Right Censored + Mean Order Number (MON) (book p.385-388)

- การวิเคราะห์จากประวัติต้องเริ่มจากเก็บข้อมูล คัดกรอง จัดลำดับความสำคัญ (ใช้ RCM, FMECA ฯลฯ) สุดท้ายต้องมีข้อมูลการเสียของอุปกรณ์เป้าหมาย: ลักษณะการเสีย จุดที่เสียหาย ประเภทงาน วันเริ่ม/เสร็จ ทรัพยากรที่ใช้ (แรงงาน อะไหล่ ผู้รับเหมา) ค่าใช้จ่าย และค่าเสียโอกาส (production loss)

### ตัวอย่างหาช่วง PM ที่เหมาะสม (book p.391-392)
- ค่าใช้จ่ายเฉลี่ยต่อครั้ง: Cp (PM/Planned) = 248,703.64; Cu (CM/Unplanned) = 1,118,558.88
- Cost per unit time = [Cu x F(tp) + Cp x R(tp)] / [tp x R(tp) + integral_tp^inf t f(t) dt]
  - tp = เวลาเข้าทำ scheduled maintenance; F(tp) = โอกาสเสียภายใน tp; R(tp) = โอกาสไม่เสียภายใน tp
  (ตัวส่วน = expected cycle length; ตัวส่วนในหนังสือเขียน integral จาก tp ถึง infinity [ตามที่พิมพ์; ตามทฤษฎี age replacement คือ integral จาก 0 ถึง tp ของ t f(t) dt])

## สรุปท้ายบท (book p.392)
- ใช้สถิติได้หลายทาง: วิเคราะห์อายุเครื่องจักร ปรับแผนซ่อม จัดการอะไหล่สำรอง; มีหลาย distribution (Poisson, Normal, Exponential, Weibull ฯลฯ)
- เลือกสมการตามลักษณะการวิเคราะห์ สมมติฐาน และความเหมาะสมของข้อมูล; Weibull ได้เปรียบสุดเพราะยืดหยุ่นตามข้อมูล
- ปัญหาแท้จริงคือขาดข้อมูลประวัติการเสีย ไม่ใช่วิธีสถิติ -> ต้องบันทึกประวัติการเสียให้ถูกต้อง ครบ ปริมาณพอ

**หมายเหตุ:** หัวข้อ Binomial, Lognormal, Geometric, Hypergeometric ถูกเอ่ยชื่อเพียงในรายการ (book p.371) แต่ไม่มีการอธิบาย pdf/สูตรในบทนี้ [หนังสือไม่ได้ครอบคลุม]. mean/variance ของแต่ละ distribution ไม่ได้ให้ไว้ (ยกเว้นวิธีประมาณ mu, sigma, lambda จากข้อมูล)

## Key terms
- Statistics — สถิติ — การประมาณจากตัวอย่างพร้อมระดับความเชื่อมั่นเพื่อตัดสินใจ — p.362
- Data Collection / Presentation / Analysis / Interpretation — เก็บ/จัด/วิเคราะห์/แปลผลข้อมูล — 4 ขั้นของระเบียบวิธีสถิติ — p.362
- Probability — ความน่าจะเป็น — โอกาสเกิดเหตุการณ์ในแต่ละหน่วย/ช่วง ค่า 0-1 — p.365, 367
- Cumulative probability — ความน่าจะเป็นสะสม — ผลรวมความน่าจะเป็นจากต้นถึงค่าที่กำหนด — p.365, 369
- Mean / Median / Mode — ค่าเฉลี่ย/มัธยฐาน/ฐานนิยม — ค่ากลาง 3 แบบ — p.366-367
- Probability Density Function (pdf, f(t)) — สมการความหนาแน่นของความน่าจะเป็น — พื้นที่ใต้กราฟ = โอกาส — p.368
- Cumulative Distribution Function (cdf, F(t), Q(t)) — ฟังก์ชันการแจกแจงสะสม — integral ของ pdf = unreliability — p.369-370
- Reliability R(t) — ความเชื่อถือได้ — โอกาสไม่เสียในช่วงเวลา t; R = 1 - Q — p.370
- Failure rate lambda(t) (hazard) — อัตราการเสีย — f(t)/R(t) — p.370
- Discrete vs Continuous function — สมการแบบช่วง/ต่อเนื่อง — จำนวนเต็ม vs ตลอดช่วง — p.371
- Poisson Distribution — การแจกแจงปัวซอง — จำนวนเหตุการณ์สุ่มต่อหน่วย (อะไหล่); f = e^-D D^x/x! — p.371
- Lead Time demand D — ปริมาณใช้ใน Lead Time — D = annual usage x LT/365 — p.373
- Normal Distribution — การแจกแจงปกติ — สมมาตรรอบ mean; params mu, sigma — p.374
- Standard deviation (sigma) — ส่วนเบี่ยงเบนมาตรฐาน — ความกระจายรอบค่าเฉลี่ย — p.374
- Exponential Distribution — การแจกแจงเอกซ์โพเนนเชียล — failure rate คงที่ lambda; cdf = 1 - e^(-lambda x) — p.376-377
- Weibull Distribution — การแจกแจงไวบูลล์ — beta/eta/gamma; ปรับรูปได้ — p.378
- Shape beta / Scale eta / Location gamma — พารามิเตอร์รูปร่าง/ขนาด/ตำแหน่ง — p.378
- Probability plot / Double Log Reciprocal Scale — กระดาษพล็อต Weibull — ทำให้ cdf เป็นเส้นตรง — p.379-380
- Median Rank (MR) — มัธยฐานลำดับ — (j-0.3)/(N+0.4) ประมาณโอกาสเสีย — p.381, 383
- Linear Regression (X / Y) — การถดถอยเชิงเส้น — หา beta, eta จากข้อมูล — p.381-382
- Complete / Right / Interval / Left censored data — ข้อมูลสมบูรณ์/ไม่สมบูรณ์ 3 แบบ — p.384-385
- Mean Order Number (MON) — เลขลำดับเฉลี่ย — ตำแหน่งเฉลี่ยของ failure เมื่อมี suspension — p.387
- MTTF — เวลาเฉลี่ยก่อนเสีย — คำนวณได้จาก Weibull parameters — p.390

## Links to compressor failure hierarchy / OREDA / ISO 14224
- Failure data requirements (p.388): ต้องเก็บ failure mode/ลักษณะการเสีย, จุดที่เสียหาย (component/location), ประเภทงาน (planned/unplanned), วันเริ่ม-เสร็จ, ทรัพยากร, ค่าใช้จ่าย, production loss -> ใกล้เคียงฟิลด์ใน ISO 14224 / OREDA maintenance record (failure mode, failure cause, item/subunit, downtime, man-hours)
- Censoring ตรงกับการจัดการข้อมูล OREDA/ISO 14224 (running time vs failure; unplanned vs planned) -> ใช้แยก F กับ S เมื่อประมาณ Weibull ของ failure mode เช่น bearing failure ของ compressor/driver
- Constant failure rate: Exponential (beta = 1) คือสมมติฐานของ failure rate lambda ใน OREDA (failures per 10^6 hr); MTTF = 1/lambda; หนังสือชี้ว่าถ้า beta = 1 time-based replacement ไม่ช่วย
- Weibull beta/eta: beta < 1 infant mortality, = 1 random, > 1 wear-out (ตัวอย่างมอเตอร์ bearing beta 3.5 eta ~997 วัน; ชุดตัวอย่าง TTF 8500-16000 ชม. beta ~3.8-3.9 eta ~13,100 ชม.)
- Spares: Poisson demand + lead time ใช้ตั้งระดับ spare stock (เชื่อมกับ spare parts critical items ของ compressor)
- PM interval optimization (Cu vs Cp, optimum 480 วัน) ใช้ตัดสินความถี่ overhaul/PM ของ rotating equipment
- หนังสือไม่มีการอ้างอิง OREDA หรือ ISO 14224 โดยตรงในบทนี้ [ไม่พบ] และไม่มี failure hierarchy (taxonomy/boundary) ของ compressor
