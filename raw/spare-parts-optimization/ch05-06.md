# บทที่ 5 หลักปฏิบัติพื้นฐานทางวิศวกรรม และนโยบายคลังพัสดุ (Engineering Basic Practice & Warehouse Policy)

Source: เรือเอก สุชาติ ศุภมงคล, "Spare Parts Optimization: การจัดการอะไหล่ให้เพิ่มผลผลิต (ฉบับปรับปรุง)" (SE-ED, 2546), book p.39-58 (PDF p35-54). หมายเหตุ: book page = PDF page + 4 (เช่น PDF p38 = book p.42, PDF p50 = book p.54); PDF p35 = หน้าปกบท (book p.39), PDF p54 = book p.58.

## บทนำ: SKU ต้องยึดหลักวิศวกรรม (book p.40)
- การกำหนดรายการสำรองคลัง (SKU = Stock Keeping Unit) ต้องอิงหลักวิศวกรรม เพราะอะไหล่มีไว้ให้เครื่องจักรพร้อมซ่อม ลดเวลาหยุดเครื่องที่กระทบการผลิต

## ขอบเขตของข้อปฏิบัติพื้นฐานทางวิศวกรรม (book p.40)
- เป็นเพียงคำแนะนำ "สต็อกขั้นต่ำ" (minimum spare parts requirements) ไม่ใช่สูตรที่การันตีว่าจะมีอะไหล่ทุกรายการตลอดเวลา -> ต้องพิจารณารายเครื่อง โดยใช้คำแนะนำผู้ผลิต สถิติการเปลี่ยนอะไหล่ และเกณฑ์ตามปัจจัย 5 ข้อ:
  1. อะไหล่ที่สึกหรอ/ผุกร่อนง่าย
  2. สภาพแวดล้อม (เช่น ใกล้ทะเล)
  3. สภาพการใช้งาน (สารละลาย กรด-ด่าง อุณหภูมิสูง)
  4. ความยากในการจัดหา (lead time นาน ไม่มีในตลาด ทำเทียมไม่ได้)
  5. ใช้ร่วมกับหลายเครื่องได้หรือไม่ / มีอะไหล่เทียบเคียงหรือไม่
- ผู้เสนอแนะจัดทำสมุดคู่มือการเก็บสต็อก = ฝ่ายวิศวกรรมโรงงานหรือผู้รับผิดชอบ (แล้วแต่โครงสร้างองค์กร)

## ตัวอย่างที่ 1: Basic Practice แบบบริษัทอเมริกัน (โรงกลั่น) (book p.40-45)

### Scope & General (book p.40-41)
- (1) ระบุ minimum spare parts สำหรับอุปกรณ์หลักของโรงกลั่น รายการเป็นแนวทาง ไม่ครบทุกชนิด
- (2) เกณฑ์เวลา: อะไหล่สำหรับ **startup + เดินเครื่องต่อเนื่อง 1 ปี**
- (3) อะไหล่ที่ต้องมีคือชิ้นที่: (1) สึกหรอ/กัดกร่อน/erosion ในการทำงานปกติ (2) เสียแล้วทำให้เครื่องหยุด (3) เสียหาย/แตกระหว่างซ่อมบำรุงหรือตรวจสภาพตามปกติ
- (4) พิจารณาเพิ่มเติม: แหล่งจัดหาอยู่ไกล, delivery นานผิดปกติ, common sparing กับเครื่องเดิม, โอกาสทำ consigned stock กับ supplier รายใหญ่
- (5) ขอ spare parts quotation โดยเร็ว ดีที่สุดคือพร้อม proposal ของเครื่อง; ต้องมี 8 ข้อมูล: equipment ID, part no. + คำอธิบาย + วัสดุ, sectional drawing ระบุตำแหน่ง/จำนวนรวม/ข้อมูลผู้ผลิต, จำนวนที่แนะนำซื้อ, ราคาต่อหน่วยและรวม, น้ำหนัก (net/shipping), delivery time, ข้อมูล interchangeability กับเครื่องอื่นในโครงการหรือที่เคยส่งให้ site นั้น -> ส่งให้เจ้าของพร้อมความเห็นต่อข้อเสนอ vendor

## นโยบายคลังพัสดุ (Warehouse Policy) (book p.55-57)
- นิยาม: เอกสารแสดงภารกิจและขอบเขตความรับผิดชอบของคลังให้ทุกฝ่ายเข้าใจ เป็นแนวทางกว้างๆ ในการควบคุมรายการสำคัญ ไม่ใช่รายละเอียดวิธีทำงาน
- ตัวอย่างนโยบายของอุตสาหกรรมหนักแห่งหนึ่ง:
  1. สต็อกพอสำหรับงานประจำวัน แต่ค่าเก็บต่ำสุด — **มูลค่าคงคลังมาตรฐานไม่เกิน 3% ของเงินลงทุนสร้างโรงงาน**; คณะกรรมการควบคุมพัสดุ/อนุกรรมการเฉพาะกิจ กำหนดวิธีเติมสต็อก (ROP, order qty, Max/Min)
  2. สต็อกมีไว้เพื่อซ่อมบำรุงปกติเท่านั้น; overhaul/turnaround ต้องวางแผนความต้องการล่วงหน้า (คลังอาจไม่พอ)
  3. อะไหล่ประกัน/เตรียมพร้อม (insurance/standby) ให้คณะกรรมการฯ พิจารณาจำนวนที่เหมาะสม
  4. มุ่งใช้พัสดุผลิต/ประกอบในประเทศที่คุณภาพยอมรับได้
  5. ส่งเสริมใช้ของ recondition โดยคำนึงความประหยัดและความปลอดภัย
  6. แบ่งพัสดุคลัง 3 ประเภท:
     - **6.1 Equipment spare parts** — ยึดคำแนะนำผู้ผลิต ทบทวนจนได้รายการสต็อก แล้วคลังคุมระดับ/เติมของ แยกย่อย:
       - Interchangeable parts (bearing, V-belt, oil seal, O-ring ฯลฯ) ซื้อจากผู้ผลิตอื่น/ในประเทศได้ รวมเก็บที่เดียว; fast/medium moving ใช้สถิติ (EOQ/ROP, Hi/Low limit); slow moving และ insurance ใช้ Min/Max ที่คณะกรรมการอนุมัติ
       - อะไหล่สึกเร็วเฉพาะเครื่อง (ต้องสั่งจาก OEM/ผู้ผลิตชิ้น) — Min/Max ต้องคิด lead time
       - อะไหล่ประกัน/เตรียมพร้อม — สำคัญแต่ราคาต่ำ คุมแบบอะไหล่สึกเร็ว; ราคาสูงต้องผ่านคณะกรรมการ
       - Instrument/Electrical/Electronic parts — Min/Max โดยผู้ชำนาญแต่ละสาขาเสนอ
     - **6.2 General used items** (ท่อ, fitting, gasket, ฉนวน, bolt/nut) — standardize ชนิด/ขนาดให้รายการน้อยลงและหาซื้อได้ทั่วไป; คุมด้วย forecast + EOQ/ROP; ซื้อน้อยแต่บ่อย ใช้ Vendor Stocking, Blanket Order; ของไม่สำคัญ หาง่าย lead time สั้น (สี, ท่อ PVC) ไม่ต้องสต็อก ซื้อเมื่อใช้และลงค่าใช้จ่ายตรง
     - **6.3 เคมีภัณฑ์งานซ่อมบำรุง** (ไม่รวมแล็บ): นำเข้า — ใช้อัตราใช้รายเดือนย้อนหลัง 6 เดือนคิดความต้องการงวดถัดไป + safety level + ความต้องการช่วง lead time, เป้าสต็อกสูงสุด **3 เดือน**; ซื้อในประเทศ — ใช้อัตราใช้ 6 เดือนล่าสุดคิดความต้องการทั้งปี แล้วทำ Blanket Order ทั้งปี (ทั้งสองแบบให้ผู้ใช้ให้ความเห็นชอบ)

## หมายเหตุและบทสรุปของบท (book p.57-58)
- คำแนะนำผู้ผลิตเป็นเพียงคำแนะนำ การตัดสินใจสุดท้ายเป็นของวิศวกร/ผู้ชำนาญของบริษัท ร่วมกับ Basic Practice; เมื่อเดินเครื่องจริง **~2-3 ปี** แล้วได้ตัวเลขที่ดีกว่า ควรปรับได้
- ไม่มีแนวทาง -> ผลเสีย 2 ด้าน: (1) อะไหล่สำคัญขาดมือ การผลิตหยุด ส่งของไม่ทัน (2) สต็อกเกิน/ของไม่เคลื่อนไหว (dead stock มูลค่าสูง) ค่าเก็บสูง ต้นทุนสินค้าสูง
- ตัวอย่างมาจากโรงกลั่นน้ำมัน (เครื่องจักรหลากหลาย อะไหล่มาก); ตัวเลขในตัวอย่างที่ 1 เป็นขั้นต่ำ ปรับเพิ่มได้
- Basic Practice สร้างจากสถิติการซ่อม/เปลี่ยนอะไหล่หลายปี หลายโรงงาน ครอบคลุม breakdown, condition-based, time-based replacement และ annual shutdown -> ใช้เป็นจุดเริ่มทำ BP ของตนเอง
- นโยบายคลังท้ายบทเขียนในรูป Work Procedure ของโรงงานแห่งหนึ่ง (book p.58)

# บทที่ 6 การจัดทำคู่มืออะไหล่ที่ใช้ได้กับเครื่องหลายเครื่อง (Parts Interchangeable Book)

Source: เรือเอก สุชาติ ศุภมงคล, "Spare Parts Optimization: การจัดการอะไหล่ให้เพิ่มผลผลิต (ฉบับปรับปรุง)" (SE-ED, 2546), book p.59-62 (PDF p55-58). PDF p55 = หน้าปกบท (book p.59).

## ทำไมต้องมีคู่มืออะไหล่ใช้ร่วม (book p.60)
- อะไหล่บางชนิดใช้กับเครื่องทั่วไป ส่วนใหญ่เป็น mechanical และ power transmission (bearing, belting, V-belt, wear ring) มีผู้ผลิตชิ้นส่วนโดยตรง (OPM — Original Part Manufacturing) หลายราย
- ถ้าไม่บันทึก จะไม่รู้ว่ามีกระจายอยู่เครื่องใด จำนวนเท่าใด; ถ้าเก็บแยกตามเครื่อง -> บริหารหลายจุด เช่น ของเครื่องหนึ่งหมดแล้วสั่งซื้อทั้งที่เครื่องอื่นยังมีเหลือ
- จึงทำสมุดคู่มือที่แสดงจำนวนรวมที่ใช้งาน และแต่ละรายการใช้ในเครื่องใดบ้าง

## ขั้นตอนการจัดทำ (book p.60-62)
1. สำรวจจาก SKU/รายการสำรองคลัง หรือเอกสารเสนอแนะของผู้ขายเครื่อง คัดเฉพาะรายการใช้ร่วมได้ ไฮไลต์และหมายเหตุว่าโอนไปกลุ่ม interchangeable
2. จัดกลุ่มตาม type, ขนาด, application; ใช้สมุดเทียบเบอร์ข้ามยี่ห้อ (เช่น ball bearing interchange ที่รวมผู้ผลิต >10 ราย) -> วิศวกรเลือกยี่ห้ออื่นได้ ไม่ต้องตาม OEM
3. ลงตาราง (ตัวอย่าง book p.61) มีคอลัมน์: ① ชื่อ part ② bin location (ระบุได้เมื่อรวมเก็บที่เดียวแล้ว) ③ คำอธิบายย่อ ④ commodity code ที่ออกใหม่ (ถ้าไม่ต้องซื้อจาก OEM ไม่ต้องใส่ OEM part no.; ถ้าต้องซื้อ OEM ใส่ Part #/Drwg # อ้างกลับเอกสารผู้ผลิต) ⑤ ส่วนขยาย เช่น วัสดุ ⑥ จำนวนรวมที่ใช้งานทั้งโรงงาน (number used) ⑦ คอลัมน์รายเครื่อง ระบุ equipment code + ส่วนขยาย (capacity, ยี่ห้อ)
4. รวมอะไหล่ตาม line item จากทุกเครื่องมาเก็บชั้นเดียวกัน (เช่น ชื่อ section "Common Used Parts")
5. ตรวจนับ (physical inventory) แล้วลงยอดในระบบ Parts Inventory
6. กำหนดนโยบายสต็อก/เติมของ: Min-Max, ROP/EOQ, Order-up-to หรือใช้ Basic Practice

- **รูปตัวอย่าง (book p.61)**: หน้า "Wear Rings Various" จาก APC Interchangeable Book — แถว = wear ring แต่ละ commodity code (322-26-xxx / 322-17-xxx, วัสดุ cast/grey iron, drawing no.) คอลัมน์ = ปั๊ม P-407AB ถึง P-516 พร้อมรุ่น/ยี่ห้อ; วิธีอ่าน: เปิดหน้าของ part (เช่น wear ring P-507A) -> เลือกคอลัมน์ปั๊ม -> ไล่ลงหาเครื่องหมาย ✓ -> อ่านไปทางซ้ายได้ commodity code (ตัวอย่าง 322-26-835); ทุกเครื่องที่มี ✓ ในแถวเดียวกันใช้อะไหล่นี้แทนกันได้. ตารางใน OCR เพี้ยนมาก ตำแหน่ง ✓ และตัวเลขเชื่อถือไม่ได้ [อ่านไม่ออก]

## ข้อแนะนำเชิงปฏิบัติ (book p.62)
- อาจใช้เวลานานถ้าขาดเอกสารผู้ผลิต หรือบันทึกรายการไม่ครบ (เช่น เขียนแค่ "Ball Bearing" ไม่รู้ชนิด/ขนาด/เครื่อง) จนสอบกลับเอกสารต้นฉบับไม่ได้ -> เสนอให้รวบรวมของจริงจากที่เก็บมาไว้ที่เดียว ให้ผู้เบิกระบุชนิด/ขนาดและเครื่องที่ใช้; คลังรวบรวมคู่มือเครื่องจักร; ตั้ง Task Force ให้เสร็จเร็ว
- Commodity Code = Stock Number ภายในบริษัท (ระบบเดียวทั้งโรงงาน) ต่างจาก Part Number ของ OEM; อะไหล่ที่มีผู้ผลิตโดยตรง (เช่น SKF bearing) ไม่ต้องสั่งด้วย OEM part number
