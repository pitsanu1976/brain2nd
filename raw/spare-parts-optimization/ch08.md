# บทที่ 8 การจัดซื้อพัสดุโรงงาน (Procurement for MRO Items)

Source: เรือเอก สุชาติ ศุภมงคล, "Spare Parts Optimization: การจัดการอะไหล่ให้เพิ่มผลผลิต (ฉบับปรับปรุง)" (SE-ED, 2546), book p.85-100 (PDF p80-95). หมายเหตุ: book page = PDF page + 5 (เช่น PDF p84 = book p.89, PDF p94 = book p.99, PDF p95 = book p.100); PDF p80 = หน้าปกบท (book p.85, ภาพจิ๊กซอว์ไม่มีข้อความ).

## บทนำ: การจัดซื้ออะไหล่ให้เพิ่มผลผลิต (book p.86)
- พัสดุโรงงาน (MRO) ซื้อยากกว่าวัตถุดิบ/พัสดุทั่วไป เพราะมีรายละเอียดทางเทคนิค; ถ้าฝ่ายจัดซื้อไม่มีความรู้ช่าง/วิศวกรรม จะซื้อผิดบ่อย
- ต้นเหตุ: ช่างใช้ศัพท์ช่าง/คำย่อ ให้ข้อมูลไม่ครบ; จัดซื้ออยากได้ตัวอย่างแนบ PR แต่บางของส่งตัวอย่างไม่ได้; ของด่วนที่ไม่ได้สต็อกไว้ จัดซื้อตอบไม่ทัน -> โยนกลับให้ผู้ขอซื้อไปซื้อเอง จนกลายเป็นเรื่องปกติ
- ข้อเสนอ: กิจการที่ซื้ออะไหล่/เครื่องมือช่างจำนวนมาก อาจตั้งตำแหน่ง **Purchasing Engineer** ในฝ่ายจัดซื้อ
- ของจากต่างประเทศต้องระบุเลขอ้างอิงและรายละเอียดพอ PR ต้องเขียนเป็นภาษาอังกฤษแบบสากล
- บทนี้ไม่ครอบคลุม Purchasing Manual/ขั้นตอนเอกสาร หัวข้อของบท: (1) การเขียน PR (2) การจัดซื้อเชิงรุก (3) เทคนิคการจัดซื้อ: Blanket Order / System Contract, Vendor Stocking, Outsourcing (4) Control on Air Freighting (5) Claims against Carriers & Suppliers

## การเขียนใบขอซื้อ (Purchase Requisition, PR) (book p.87-88)
- ผู้รับผิดชอบเขียน PR: ซื้อเข้าสต็อก = ผู้จัดการคลังพัสดุ; ซื้อแล้วใช้เลย (direct charge) = ผู้รับผิดชอบศูนย์ค่าใช้จ่ายนั้น (อ้างบทที่ 1 การบริหารวัสดุและการบันทึกบัญชี)
- สาระสำคัญของ PR:
  1. **รหัสบัญชี** ตามผังบัญชี: Inventory A/C (ซื้อเข้าคลัง), รหัสค่าใช้จ่าย = ศูนย์ค่าใช้จ่าย + ลักษณะค่าใช้จ่าย (ซื้อใช้เลย), รหัสลงทุน (ทรัพย์สินถาวรที่อนุมัติแล้ว)
  2. **รายละเอียดพอเพียง**: ขึ้นต้นด้วยชื่อหลัก (nomenclature / main name) แล้วตามด้วยส่วนขยาย
- ตัวอย่างถูก/ผิด:

| ถูก (ชื่อหลักก่อน) | ผิด |
|---|---|
| Flange Slip-On ASA B 16.5 ASTM A-181-I 150 psi. size 4" | ASA B 16.5 ASTM A-181-I 4" 150# Slip-On Flange |
| Elbows 45° LR stdwt. Sch-40 ASTM A-234 4 inch | 4 inch sch 40 LR. 45° Elbow ASTM A-234 |

- คำอธิบาย Elbow: มุม 45°, LR = long radius, ความหนา standard weight / Sch 40, วัสดุตาม ASTM A-234, 4" = nominal pipe size ใช้กับท่อ 4 นิ้ว; มีรูปข้องอ 45° พร้อมป้าย "4" - 45° ELBOW x STD WT"
- ตัวย่อต้องเป็นมาตรฐานสากล: ค้นจาก Abbreviation Dictionary และแคตตาล็อก (เช่น McMaster catalog, Tube-Turn catalog)
- ผู้ขอซื้อต้องรับผิดชอบให้รายละเอียดดี; ควรฝึก OJT/ดูงานให้จัดซื้อ และส่งคู่มือ แคตตาล็อก หนังสืออ้างอิงให้จัดซื้อศึกษา

### ข้อแนะนำในการเขียนรายละเอียดวัสดุ (book p.88)
1. ชื่อภาษาไทยทำให้เข้าใจผิดได้ เพราะของช่างเรียกได้ 3 แบบ: ภาษาช่าง / ชื่อทางการค้า / ชื่อสากล(อังกฤษ) -> ใช้ชื่ออังกฤษ เหมาะทั้งซื้อในและต่างประเทศ
2. ระบุส่วนขยายให้ครบ
3. ใช้เลขอ้างอิง: Stock Number / Part Number / Drawing Number ฯลฯ
4. ถ้ามีแคตตาล็อกพัสดุ + คุณลักษณะเฉพาะ ใช้เลขแคตตาล็อก/เลขเฉพาะแทนรายละเอียดทั้งหมดได้
5. ห้ามใช้ของเทียบเท่า -> เขียน "No Substitution Permit" หรือ "Do not Substitute"
6. ยอมรับของเทียบเท่า -> เขียน "<ยี่ห้อ> or Equivalent" (ตัวอย่างในหนังสือ: "Rigid or Equivalent")
- หมายเหตุ: จำนวน หน่วยนับ วันที่ต้องการ ลายเซ็นขอซื้อ/อนุมัติ เป็นไปตามข้อกำหนดของแต่ละบริษัท

## การบริหารการจัดซื้อเชิงรุก (book p.88-90)
- จัดซื้อต้องรู้กระบวนการผลิต ระบบพลังงาน เครื่องจักร ระบบไฟฟ้า/แสงสว่าง/อิเล็กทรอนิกส์/เครื่องกล; หมุนเวียนพนักงานจัดซื้อไปดูงาน/OJT กับผู้เขียน PR -- การซื้อของที่ไม่รู้จักขาดประสิทธิภาพ
- **การจัดซื้อเชิงรุก = up-stream purchasing**: เตรียมล่วงหน้าว่าจะซื้ออะไร ที่ไหน lead time เท่าไร ตรวจรับอย่างไร ขนส่งและเก็บรักษาอย่างไร
- **ขั้นตอนที่ 1**: ใช้สถิติจัดซื้อย้อนหลัง 2-3 ปี+ คัดรายการที่ใช้มาก/สั่งถี่ แล้วกรองต่อหารายการสำคัญที่มีปัญหาเลือกผู้ค้า/lead time ยาว/กำหนด spec ยาก (ตัวอย่าง: จาก ~10,000 รายการ เหลือ ~200 รายการ)
- **ขั้นตอนที่ 2**: ทำแคตตาล็อกและใบคุณลักษณะเฉพาะ (Specification sheet) ให้ทั้ง ~200 รายการ โดยผู้ใช้/ฝ่ายเทคนิคทำร่วมกับจัดซื้อ (ซึ่งรู้แหล่งขายดีกว่า); จากนั้นอ้าง **Specification No.** ทุกครั้งที่ซื้อ (เทียบการอ้าง Military Standard / Mil No.) แล้วค่อยขยายไปรายการอื่น
  - ตัวอย่างใบ spec (book p.89, ตารางไม่มีเลขรูป): หัวฟอร์มมี รหัสวัสดุ, ชื่อทางการค้า, ชื่อทางเคมี, Spec. No, ตรวจสอบโดย/อนุมัติโดย/วันที่, จำนวนหน้า, จัดเก็บที่; เนื้อหาแบ่ง (1) คุณสมบัติเคมี: SG (20°C) ≈1.0, จุดเดือด 100°C, จุดวาบไฟ 42°C, pH 6-8 (2) คุณสมบัติกายภาพ: ของเหลวใสไม่มีสี กลิ่นหอมระเหย ละลายในน้ำ/แอลกอฮอล์/อะซีโตน ละลายเล็กน้อยในเบนซิน ไม่ละลายในอีเทอร์ ภาชนะต้องปิดสนิท (3) การเก็บรักษา: ที่แห้ง ระบายอากาศดี ห่างกรด oxidizing agent ประกายไฟ
- **ขั้นตอนที่ 3**: จัดซื้อออกหาแหล่งขาย/ผลิตทันที ไม่ต้องรอ PR: เชิญลงทะเบียน Vendor List, อธิบายข้อกำหนด/เงื่อนไข, ขอราคาเบื้องต้นหรือสืบราคา, ของใช้ประจำปริมาณมาก -> พิจารณา Blanket Order, System Contract, Vendor Stocking, Outsourcing

## เทคนิคการจัดซื้อ (book p.90)
- การบริหารพัสดุยุคใหม่ไม่เก็บสต็อกมาก -> ทยอยซื้อเท่าที่ต้องการแต่บ่อยขึ้น จัดซื้อต้องเตรียมการดีขึ้นและมี service mind; JIT, Stockless Purchasing, Vendor Stocking มีรากเดียวกัน
- 4 รูปแบบ: (1) Blanket Order (2) System Contracting (3) Consignment และ Vendor Stocking (4) Outsourcing

## Blanket Order (BO) (book p.91-92)
- ที่มา: บริษัทใหญ่ในสหรัฐฯ เริ่ม ก.พ. 1966 (พัฒนามาตั้งแต่ต้น 1965) แก้ปัญหาซื้อวัตถุดิบที่ต้องการบ่อยและมาก
- เหตุผลสำคัญ: ใบขอซื้อมูลค่า < 300 USD/ใบ มีจำนวน **60%** ของใบทั้งหมด แต่มูลค่ารวมเพียง **5%** -> ของถูกจำนวนมากไม่ควรใช้ขั้นตอนยุ่งยากเท่าของแพง
- วิธีการ: ผู้ใช้พยากรณ์ความต้องการทั้งปีจากความต้องการรายงวด (ตัวอย่าง 5,000 อัน/เดือน -> 60,000 อัน/ปี); PR ทำ 1 ใบต่อ 1 รายการ หรือ 1 ใบหลายรายการได้ ถ้าเป็นของคล้ายกันจากแหล่งเดียวกัน
- เงื่อนไขการรับของ (เลือก 1 แบบ):
  1. ระบุจำนวน + ส่งสม่ำเสมอตามเวลา
  2. ระบุจำนวน + ส่งภายในกำหนดเวลา
  3. กำหนดเวลา ไม่ระบุจำนวน
  4. กำหนดเวลา มีประมาณการแต่ไม่ยืนยันการสั่ง
  5. กำหนดเวลา ยืนยันการสั่งขั้นต่ำ
- จัดซื้อคัดผู้ค้าจากราคา บริการ ความสามารถรับเงื่อนไข BO แล้วออก PO แบบ BO
- **การรับของเป็นงวด**: ผู้ใช้ออก **Blanket Order Release (BOR)** ระบุจำนวนงวดนั้น อ้างเลข BO + ลำดับครั้ง (เช่น BO No. 0123/1); สั่งทางโทรศัพท์ได้โดยกำหนดผู้ติดต่อประจำและบันทึกการโทร; ผู้ค้าส่งของพร้อม invoice หรือ D/O และรับ BOR; ผู้ขอซื้อเซ็นรับแล้วทำ **Partial Delivery Receipt (PDR)** ส่งบัญชีจ่ายเงินตามงวด สำเนาให้จัดซื้อ update -- เอกสารบริษัทกับผู้ค้าต้องตรงกันเสมอ
- ปัญหา: ผู้ค้าไม่อยากยืนราคาตลอดอายุ BO ขณะที่ผู้ซื้อต้องการความแน่นอนด้านราคา (นอกเหนือจากประหยัดเวลา/เอกสาร)
- ข้อแนะนำ: ระบุยืนราคาตลอดอายุ BO; ระบบ JIT ต้องพึ่งผู้ค้าที่ดี; เสนอ clause ตัวอย่าง (สรุปความ): ยืนราคาตามช่วงวันที่กำหนด (ตัวอย่าง 3 ม.ค.-29 ธ.ค. 2547) ปรับขึ้น/ลงได้ทั้งสองฝ่ายเมื่อมีเหตุผลทางเศรษฐกิจที่ประกาศโดยสื่อ/รับรองโดยสมาคมหรือหน่วยราชการ และการเปลี่ยนแปลงต้องเกิน ±X% (เว้นว่างให้กรอก)

### แบบฟอร์ม PDR (book p.93)
- คอลัมน์: Item / Quantity (จำนวนครอบคลุมตาม PO) / Unit / Qty before this delivery / Description / Quantity Received / Qty after this delivery; หัวฟอร์ม Date, Order No., Voucher No., Attachment No.; ช่องเซ็น Receiving Clerk ("received in good condition"), Purpose, Charge to, Passed for payment

| ครั้ง | วันที่ | ก่อนส่ง | รับครั้งนี้ | คงเหลือ |
|---|---|---|---|---|
| BO 0123/1 | 23 มี.ค. 2546 | 60,000 | 2,500 | 57,500 |
| BO 0123/2 | 15 เม.ย. 2546 | 57,500 | 5,000 | 52,500 |

## การจัดซื้อด้วยการทำสัญญาอย่างมีระบบ (System Contracting) (book p.92, 94)
- นิยาม: สัญญาครอบคลุมหลายรายการในกลุ่มพัสดุเดียวกัน ระบุราคา lead time การรับประกันว่ามีสต็อกพร้อมส่งตลอด; ผู้ซื้อต้องมีรายการ spec ความรับผิดชอบ จำนวน และเงื่อนไขแบบประนีประนอม
- ขั้นตอน: สัญญามีผลแล้ว ผู้ใช้ติดต่อสั่งตรงกับผู้ค้า (โทรศัพท์/แฟกซ์) ด้วยใบสั่งย่อย (Delivery Order Release / Partial Delivery Release) -> ผู้ค้าส่งของพร้อม D/O / packing list / invoice อ้างเลขใบสั่งย่อย -> ผู้รับตรวจคุณภาพ/จำนวน เซ็นกำกับทุกรายการ = **ใบ Tally** -> ส่งต้นฉบับที่อนุมัติจ่ายให้แผนกจ่ายเงินทุกสิ้นวัน/ตามตกลง; ผู้ค้ารวบรวมใบ Tally + ใบปะหน้าเบิกเงิน
- แผนกจ่ายเงิน 3-way check: (1) ต้นฉบับจากผู้รับของ (2) ใบเรียกเก็บของผู้ค้า (3) ราคาตามสัญญา
- ต่างจาก BO: รายการมากกว่าหรือไม่กำหนดรายการ และมีสัญญากำกับ PO เพื่อความแน่นอน
- เป็นรากฐานของ JIT -> มั่นใจพอจะ zero stock รายการนั้น ลดค่าเก็บรักษา; กลุ่มน้ำมันและรถยนต์ในสหรัฐฯ ขยายใช้
- ผลดี 5 ข้อ: (1) ลดพัสดุคงคลังมาก บางรายการไม่ต้องสต็อก (2) ลดงานจัดซื้อ ซื้อ-ส่งง่ายเร็ว (3) ราคาดีกว่าซื้อรายครั้ง เพราะต่อรองและรู้โครงสร้างราคา (4) รู้ความต้องการ/ราคาแน่นอน คำนวณต้นทุนแม่น ใช้ JIT/MRP ได้ดีขึ้น (5) ใช้ราคาสัญญาเป็นมาตรฐานสืบราคา/ประมูลงานที่โครงสร้างราคาคล้ายกัน

## สินค้าฝากขาย (Consignment Materials) (book p.95)
- จ่ายเงินหลังใช้ของแล้ว (แบบห้างสรรพสินค้า: ไม่ลงทุนในสินค้าคงเหลือ จ่ายเฉพาะที่ขายได้ และยังถือเงินไว้ได้อีกระยะ)
- ใช้กับคลังโรงงานได้ ถ้าตลาดเป็นของผู้ซื้อ (ผู้ขายต้องง้อ): ผู้ค้านำของมาฝากในคลังผู้ซื้อ -> มาตรวจนับ -> วางบิลเฉพาะจำนวนที่จ่ายออก -> เติมให้เต็มระดับเดิม
- คลังบันทึกสต็อกการ์ดว่าจ่ายออกชาร์จบัญชีใด แล้วใส่รหัสบัญชีใน Payment Order (ชาร์จตรงวันที่ผู้ค้ามาเก็บเงิน)
- ผู้ค้ารับผิดชอบควบคุมระดับคงคลังเอง (แจ้งยอดทางโทรศัพท์)

## Vendor Stocking (book p.95)
- ตกลงซื้อแล้วแต่ให้ผู้ค้าเก็บของไว้ก่อน จนกว่าจะแจ้งให้ส่งมาหรือส่งไปที่ใด; อาจต้องชำระตามงวดไม่ว่าส่งแล้วหรือยัง; อาจมีค่าเก็บถ้าเกินเวลาที่ตกลง
- ตัวอย่าง: สินค้าอันตราย, สินค้ารอส่งไปต่างประเทศ
- หมายเหตุ: Consignment ก็เป็น Vendor Stocking แบบหนึ่ง แต่ของเก็บอยู่ที่สถานที่ของผู้ซื้อ

## Outsourcing (book p.96-97)
- หลัก: ใช้ผู้ชำนาญภายนอกเมื่อต้องการ ควรได้คุณภาพดีกว่าและถูกกว่า; เริ่มจากงานที่ไม่ใช่งานหลัก (core)
- ปัจจัยเลือกงานที่ outsource ได้ (ต้องไม่เสี่ยง):
  1. ด้านบริการต่อเนื่อง (ถ้าผู้รับเหมาหยุดงานแล้วกระทบกระบวนการข้างเคียงมาก)
  2. ด้านการควบคุมต้นทุน/เปิดเผยข้อมูลราคา
  3. ด้านสูตรการผลิต/คุณสมบัติพิเศษของสินค้า (เสียเปรียบทางการตลาด)
- ที่มา: ทำเองแพงกว่า เพราะต้องลงทุนเครื่องมือและบริหารบุคคล
- ตัวอย่างงาน: ด้านวัสดุ/จัดซื้อ = จัดซื้อ, บริหารวัสดุ, คลังสินค้า/คลังวัสดุ, กระจายสินค้า, Salvage and Disposal; ด้านอื่น = Records & File Maintenance, System Support, พิธีการศุลกากร/นำของออกจากท่าเรือ, บริหารบุคคล, ซ่อมบำรุง (เครื่องจักร เครื่องยนต์ ยานยนต์ อาคาร ระบบบำบัดน้ำเสีย), ส่งเสริมการขาย, ประชาสัมพันธ์ (เหมาะหรือไม่ขึ้นกับนโยบายกิจการ)
- ข้อแนะนำ: (1) outsource เพียงบางส่วนได้ (เช่น HR ให้แค่สรรหา ส่วนสวัสดิการ/เงินเดือนทำเอง) (2) ต้องพิสูจน์ว่าดีกว่าจริง เช่น เทียบราคาผู้รับเหมากับค่าใช้จ่ายรวมของการทำเอง (3) พิจารณาการใช้ทรัพยากรทั้งหมด (สาธารณูปโภค บุคลากร เวลา ทรัพย์สิน)
- งานซ่อมบำรุงเครื่องจักร/ยานยนต์/อาคาร/คอมพิวเตอร์/กำจัดของเสีย มีโอกาส outsource สูง เพราะมีผู้รับจ้างจำนวนมาก

## การควบคุมการขนส่งทางอากาศ (Control on Air Freighting) (book p.97-98)
- ค่าขนส่งทางอากาศสูงสำหรับของใหญ่/หนัก จึงต้องควบคุม
- เกณฑ์: ผู้อนุมัติต้องเป็นผู้บริหารระดับ Management Executive ที่คุมค่าใช้จ่ายคลังและซ่อมบำรุง และสูงกว่าผู้จัดการคลังและผู้จัดการซ่อมบำรุง **1 ระดับ**; อนุมัติเฉพาะกรณีเร่งด่วน/ฉุกเฉินจากเหตุสุดวิสัยที่จะเสียหายร้ายแรงต่อโรงงาน ผลิตภัณฑ์ หรือโอกาสทางธุรกิจ
- อนุมัติเฉพาะจำนวนที่ด่วน: ต้องการ Boiler Tubes 20 เส้น จากที่สั่ง 100 เส้น -> air freight แค่ 20 เส้น
- แนวปฏิบัติ 6 ข้อ:
  1. PR ที่ขอ air freight ต้องมีเหตุผลประกอบ
  2. ผู้ขอควรแนะนำสายการบิน; หน่วย Purchasing Traffic ควรแนะนำเที่ยวบินตรง (ต่อเครื่องหลายทอดเสี่ยงของหาย ส่งผิดเมือง หีบห่อเสีย ล่าช้า)
  3. ผู้อนุมัติ PR ต้องลงชื่อย่อกำกับคำว่า "Air Freight" กันการเติมคำภายหลัง
  4. คลังพัสดุต้องยืนยันว่าไม่มีของในสต็อก/รายการค้างรับ
  5. จัดซื้อตรวจตัวแทนจำหน่ายในประเทศก่อน (อาจมีสต็อกและถูกกว่าสั่ง air freight เอง)
  6. บันทึกค่า air freight ของที่มากและหนักรายปี เพื่อวิเคราะห์สาเหตุความเร่งด่วนและป้องกัน

## การเรียกร้องสินค้าชำรุด (Claims against Carriers & Suppliers) (book p.98-100)
### ผู้ค้าในประเทศ
- จัดซื้อเป็นตัวแทนบริษัท รับผิดชอบเรียกร้องให้ทดแทน; ผู้รับพัสดุ/คลังเตรียมหลักฐาน (ข้อมูลการรับ รูปถ่ายสภาพชำรุด)
- ข้อตกลงอื่นนอกจากส่งของทดแทน (หักเงิน ยกเลิกรายการ) ต้องได้รับอนุมัติ
- คืนของต้องมีใบผ่านประตู หมายเหตุ "Returned for Credit"

### ผู้ค้าต่างประเทศ
- ความรับผิดของผู้ค้า/ผู้ส่ง/ผู้ขนส่ง และประกันภัยระหว่างขนส่ง ดูตาม Incoterms; บทนี้กล่าว 3 กรณี:
  1. **สินค้าชำรุด**: ประเด็นสำคัญสุดคือพิสูจน์ว่าชำรุดก่อนถึงมือผู้ซื้อ; เรียกร้องช้าหรือใช้ของไปแล้วอาจถูกปฏิเสธ -> ตรวจทันทีเมื่อพบหีบห่อเสียหาย ถ่ายรูปดิจิทัล/วิดีโอ, ของนำเข้าตรวจที่ท่าเรือ/ท่าอากาศยาน/ตอนเปิดตู้, มีพยาน (ศุลกากร การท่าเรือ) ลงชื่อหรืออยู่ในภาพ, ตั้งประเด็นเบื้องต้นว่าผิดที่ผู้ขนส่งหรือผู้ค้า
  2. **ได้รับของขาด**: รายงานทันทีด้วยรายงานรับสินค้าและแจ้งจัดซื้อ; รับตามจำนวนจริง ปรับยอดคงเหลือตามจริง แจ้งผู้ค้าให้ชดเชยทันที; รับบางส่วนและจ่ายเงินเฉพาะของดีที่ได้รับ
  3. **รับของเกิน (over shipment)**: ถ้ารับเข้าสต็อก ราคาต่อหน่วยจะลดลง -> พัสดุ MRO ใช้วิธีเฉลี่ยราคา (ถ้าทำได้); สินค้าซื้อมาขายไปอาจมีปัญหาบัญชี/สรรพากร อาจต้องส่งคืน

### คำแนะนำการบันทึกการเรียกร้อง (book p.99)
1. ใบเรียกร้องต้องมี Claim Number เพื่อบันทึก/ติดตาม
2. บัญชีได้สำเนาทุกใบ เพื่อระงับการจ่ายเงิน
3. การเรียกค่าเสียหายเป็นเงิน พิจารณาเป็นกรณีที่เสียหายร้ายแรง
4. ต้องมีหลักฐาน พยาน เอกสาร รูปถ่าย ไม่มีหลักฐาน = ไม่ได้รับการชดเชย
5. ติดตามจำนวนเรื่องและมูลค่าทุกเดือน = รายงาน **Status of Claims**
6. เรื่องมูลค่าน้อยอาจไม่คุ้มค่าติดตาม จึงอาจละเว้นได้

### ตัวอย่างแบบฟอร์มใบเรียกร้อง (book p.100)
- "รายงานเรียกร้องสินค้าผิดคุณลักษณะเฉพาะ / Statement of Claim": Claim No., To, Date, อ้างถึง PR/PO, C/O, Address, Receiving Point, Shipping Documents, Supplier, ผู้จัดส่ง
- ตาราง: Item / Ref / Run Store No / Irregular Found / Quantity / Unit / Price per Unit
- Supporting Document: Photo / Attachment / Other; Corrective action: Replace within ... days / Returned and cancelled / Other
- ลายเซ็น: Receiving Clerk, ผู้จัดการหน่วยงานที่รับผิดชอบ, Purchasing Dept. Mgr.; ช่อง Result of Claim

## ข้อสังเกต / ข้อผิดพลาดที่พบ
- การคำนวณตรวจแล้วถูกต้อง: 5,000 x 12 = 60,000; PDR 60,000 - 2,500 = 57,500; 57,500 - 5,000 = 52,500
- ตัวอย่าง Flange "ถูก" ระบุ "150 psi" แต่ตัวอย่าง "ผิด" ใช้ "150#" -- ตาม ASME B16.5 ค่า 150 คือ pressure class (Class 150 / 150#) ไม่ใช่ 150 psi; น่าจะเป็นความคลาดเคลื่อนของหนังสือ (ความรู้ทั่วไป ไม่ใช่จากแหล่ง)
- "Rigid" ในตัวอย่าง "Rigid or Equivalent" น่าจะหมายถึงยี่ห้อเครื่องมือ RIDGID; "Mcmaster Catalog" = McMaster-Carr
- OCR ผิด: หัวกระดาษ "การจัดกระยะให้มีผลผลิต"/"การจัดการอะไรให้..." = "การจัดการอะไหล่ให้เพิ่มผลผลิต"; "หมายเลขช้างอิง" = อ้างอิง; "อะไรใส่ละไรบ้าง" = อะไหล่อะไรบ้าง; "โครงสร้างด้านราคาล้ายๆ" = คล้ายๆ; "วัสดุสิบ" [อ่านไม่ออก] น่าจะ "วัสดุสิ้นเปลือง"; "Partial Deliver Receipt" = Partial Delivery Receipt; "Personal Management" = Personnel Management
- หัวข้อ "3. ข้อแนะนำสำหรับผู้ซื้อ..." เลขลำดับต่อจากสาระสำคัญของ PR (ข้อ 1-2) ทั้งที่เนื้อหาเป็นข้อแนะนำสำหรับ "ผู้ขอซื้อ"
- บทนำระบุเทคนิค 3 กลุ่ม (BO/System Contract, Vendor Stocking, Outsourcing) แต่หัวข้อเทคนิคการจัดซื้อแจกเป็น 4 รูปแบบ (แยก Consignment & Vendor Stocking)
- ตัวอย่าง PDR ลงวันที่ปี 2546 แต่ clause ยืนราคาตัวอย่างใช้ปี 2547 (ไม่ขัดกันโดยตรง เป็นเพียงตัวอย่าง)
- ตาราง spec sheet ตัวอย่าง (PDF p84) วางก่อนข้อความขั้นตอนที่ 2 ที่อ้างถึง; ไม่ระบุชื่อสารเคมี
- ฟอร์มใบเรียกร้อง: ช่อง "อ้างถึงใบขอซื้อและใบสั่งซื้อ" จับคู่กับ "Address" และ "ผู้จัดส่ง" = "Deliver" -- น่าจะเป็นความผิดจาก OCR/การจัดวาง
