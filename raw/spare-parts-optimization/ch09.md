# บทที่ 9 การบริหารระดับคงเหลือพัสดุโรงงาน (Inventory Control for MRO Items)

Source: เรือเอก สุชาติ ศุภมงคล, "Spare Parts Optimization: การจัดการอะไหล่ให้เพิ่มผลผลิต (ฉบับปรับปรุง)" (SE-ED, 2546), book p.101-110 (PDF p96-105). หมายเหตุ: book page = PDF page + 5; PDF p96 = หน้าปกบท (book p.101, ภาพจิ๊กซอว์), PDF p99 มีหัวกระดาษ "104", PDF p105 มี "110".

## บทนำ: การควบคุมระดับคงเหลือ (book p.102)
- รายการที่คัดเลือกให้เก็บสำรองคลัง (ตามบทที่ 3): อะไหล่พิเศษเฉพาะเครื่อง, อะไหล่ประกันเตรียมพร้อม, อะไหล่ใช้ได้หลายเครื่อง, อะไหล่/อุปกรณ์ลักษณะทรัพย์สินถาวร, วัสดุทั่วไป/ของสิ้นเปลือง, เคมีและก๊าซ
- เรียกว่า regular stock items; นับจำนวนรายการเป็น SKU (stock keeping unit); มูลค่าเข้าบัญชี inventory account
- Inventory control = รักษาระดับคงเหลือให้พอใช้ครั้งต่อไป โดยสั่งเติม (stock replenishment) ไม่มากหรือน้อยเกินไปเมื่อเทียบแนวโน้มความต้องการ; วิธีหาจำนวนสั่งที่เหมาะเรียก order control procedure
- หลัก 2 ข้อ: (1) สั่งเมื่อไร (เมื่อคงเหลือเท่าไร) (2) สั่งครั้งละเท่าไร
- ซอฟต์แวร์ทั่วไปให้ผู้ใช้ตั้ง Min-Max เอง -> ไม่เหมาะกับของใช้มาก มูลค่าสูง หมุนเร็ว หรือ lead time นาน (ต้องมีสต็อกช่วงจัดหา + ระดับปลอดภัยรองรับความเบี่ยงเบน); Min-Max อาจใช้ได้กับของเคลื่อนไหวช้าที่ไม่มีสถิติ โดยอาศัยข้อปฏิบัติพื้นฐานทางวิศวกรรมช่วยกำหนด

## วิธีควบคุมการสั่งซื้อใหม่ที่นิยม 6 วิธี (book p.103)
1. ROP/EOQ (จุดสั่งซื้อ + จำนวนสั่งซื้อที่ประหยัด)
2. High Limit-Low Limit (คำนวณจำนวนสำรองสูงสุด-ต่ำสุด)
3. Min-Max (กำหนดเอง)
4. Periodic Review & Replenishment Cycle (ตรวจนับตามรอบแล้วเติมให้เต็ม)
5. Order Up-to (สั่งแทนของที่ถูกเบิกทันที)
6. Order as Required (OAR, สั่งเมื่อต้องใช้เท่านั้น)

## ROP/EOQ (book p.103-106)
- ผู้เขียนเห็นว่ามีเหตุผลที่สุดเพราะใช้หลักเศรษฐศาสตร์: ซื้อครั้งละมาก -> ค่าเก็บ/เงินลงทุนสูง; ซื้อครั้งละน้อย -> สั่งบ่อย ค่าสั่งซื้อสูง และเสี่ยงของขาด (ค่าเสียหายจากสต็อกขาดอาจมากกว่าค่าเก็บ) -> EOQ คือจุดที่ต้นทุนรวมต่ำสุดระหว่างค่าเก็บกับค่าสั่ง
- **รูปที่ 9.1** (book p.103): กราฟ Dollar Costs vs Order Quantity: เส้นค่าเก็บสต็อกเฉลี่ย 1 ปีขาขึ้น, เส้นค่าสั่งซื้อตามความต้องการทั้งปีขาลง, Total Annual Cost รูปตัว U, EOQ ที่จุดต่ำสุด
- **สูตร** (book p.104): **EOQ = √(2·A·CO / (C·I))**
  - A = ความต้องการทั้งปี (จากค่าพยากรณ์ต่องวด standard interval เช่น สัปดาห์/เดือน)
  - CO = Cost of Order ค่าสั่งซื้อ 1 รายการ 1 ครั้ง (ไทยควรอยู่ราว **90-120 บาท**)
  - C = ราคาต่อหน่วย
  - I = Investment Factor: ค่าใช้จ่ายการเก็บเป็น % ของมูลค่าสต็อก (ค่าเงินลงทุน เช่น ดอกเบี้ย/rate of return ที่ต้องการ + ค่าใช้จ่ายคลังอื่น)
- แบบฟอร์มรายงาน COP (Cost of Possession) รายปี (book p.104): ระบุ inventory at year end, average inventory; รายการ (บาท และ %): 1) ผลประโยชน์จากเงินลงทุน 2) ประกันภัย 3) ค่าเช่าพื้นที่คลัง 4) ค่ายกขนเคลื่อนย้าย 5) ค่าบริหาร/ควบคุม 6) ความเสียหายจากล้าสมัย/เสื่อม 7) ของหาย; รวม = COP
- ข้อจำกัดของ EOQ (book p.105):
  - ต้องมีสถิติ/อัตราการใช้พอสมควร -> เหมาะกับวัสดุทั่วไป เคมี ชิ้นส่วนสิ้นเปลือง อะไหล่ใช้หลายเครื่อง และของหมุนเร็ว
  - ผลอาจได้จำนวนน้อยต้องสั่งบ่อย -> แก้ด้วย Blanket Order / สัญญาอย่างเป็นระบบ
  - ได้ผลสูงสุดเมื่อปรับตัวแปรแบบพลวัต (ราคา/อัตราใช้เปลี่ยน -> EOQ ต้องเปลี่ยนตาม)
- **จุดสั่งซื้อ** (book p.105): **ROP = (D × LT) + SS**
  - D = อัตราการใช้/ค่าพยากรณ์จากสถิติ; LT = lead time จากสถิติที่ผ่านมา; D × LT = ความต้องการช่วงจัดหา
  - SS = safety stock; สำหรับ MRO ผู้เขียนใช้ % ความผิดพลาดในช่วงจัดหา = ความเบี่ยงเบน lead time + ความเบี่ยงเบนอัตราใช้ (ตัวอย่างตั้ง 10% + 10% = 20%)
  - ตัวอย่าง: D = 20, LT = 2 เดือน -> D×LT = 40; SS = 20% × 40 = 8; **ROP = 40 + 8 = 48**
- ROP มีเหตุผลกว่าการตั้ง Minimum ตรงๆ; ถ้าเทียบกับ Min-Max: **Mid = ROP = 48, Min = SS = 8**, จำนวนสั่งต่อครั้ง = EOQ (book p.105-106) — ข้อเสนอแนะสำหรับรายการหมุนเร็ว

## High Limit / Low Limit (book p.106-107)
- ไม่ใช่ Min-Max ตรงๆ เพราะต้องคำนวณและกำหนด **Stockage Objective** — ใช้ในกองทัพสหรัฐ (อ้างอิง Busanda: Bureau Supply and Account)
- Stockage Objective = ระยะ/ปริมาณเก็บสต็อกนานที่สุดที่ยังดำเนินงานได้โดยไม่ต้องเบิกคลังใหญ่ (= สต็อกสูงสุด) เหมาะกับอะไหล่หมุนเร็วถึงปานกลางที่พยากรณ์อัตราใช้ได้ (forecasting approach)
- **High Limit = D × ระยะ Stockage Objective**; **Low Limit = ROP = (D × LT) + SS**
- ตัวอย่างก๊าซออกซิเจน: D = 40 ท่อ/เดือน, Stockage Objective 3 เดือน -> High Limit = 120 ท่อ; LT = 1/2 เดือน, SS = 10% ของ D×LT -> ROP = 20 + 2 = **22** (SS = 2, Low Limit = 22)
- **จำนวนสั่ง = Stockage Objective (High Limit) − On Hand** ณ วันสั่ง (book p.107):
  - สั่งเมื่อเหลือ 22 พอดี -> 120 − 22 = **98**
  - ใช้เลยจุดสั่งจนเหลือ 10 -> 120 − 10 = **110**
- หมายเหตุ: High/Low Limit เปลี่ยนทันทีเมื่ออัตราใช้เปลี่ยน; ผู้เขียนว่าดีกว่า Min/Max และสะดวกกว่า ROP/EOQ; ของหมุนเร็วควรสั่งผ่าน Blanket Order
- **รูปที่ 9.2** (book p.107): กราฟระดับคงคลังกับเวลา แสดง Stockage Objective/High Limit, Low Limit = ROP, ช่วง Lead Time Demand (D × LT) และ Safety Stock

## Min-Max (book p.107)
- กำหนดจากข้อปฏิบัติพื้นฐานทางวิศวกรรม/ผู้ชำนาญ โดยคาดคะเนหรือจับสถิติบ้าง -> ผิดพลาดสูง โดยเฉพาะเมื่อตั้งหลายพันรายการในเวลาสั้น
- แต่ใช้ได้ผลกับของหมุนช้ามาก จำนวนสำรองน้อย — Min-Max ในย่านตัวเลขต่ำดีกว่าการคำนวณสองวิธีข้างต้น

## Periodic Review (PRM) (book p.108-109)
- ตรวจนับเป็นงวดตามรอบคงที่ (fixed periodic replenishment cycle) แล้วสั่งเติมเท่าที่หมดไป (replenish stock) เช่น ตรวจเดือนละครั้ง สั่งเดือนละครั้ง
- ตรงข้ามกับ ROP/EOQ ซึ่งสั่งเมื่อคงเหลือถึง ROP (ไม่ขึ้นกับรอบตรวจ) และจำนวนสั่ง (EOQ) เกือบคงที่:

| | เมื่อไร | เท่าไร |
|---|---|---|
| PRM | Fix | Vary |
| EOQ | Vary | Fix |

- ปัญหาของ PRM: สั่งครั้งแรกเท่าไร และรอบตรวจยาวเท่าไรดีที่สุด -> ต้องเลือก R (Review Time) และ M (Maximum Quantity); ทุกรอบ R ตรวจแล้วเติมให้เต็มถึง M
- **สูตร: จำนวนสั่งใหม่ = M − (OH + QOD)** (OH = คงเหลือ, QOD = จำนวนค้างรับ/สั่งค้าง)
  - ตัวอย่าง: M = 90, ค้างรับ 30, คงเหลือ 25 -> 90 − 55 = **35**
  - ตรวจปลายเดือนเหลือ 10 ไม่มีค้างรับ -> 90 − 10 = **80**
- เหมาะกับวัสดุราคาต่ำหมุนเร็วที่แยกบริหารแบบซูเปอร์มาร์เก็ต (อ้างบทที่ 7)

## Order Up-to (book p.109)
- กำหนดจำนวนคงคลังคงที่ (อาศัยข้อปฏิบัติพื้นฐานทางวิศวกรรม บทที่ 5) เบิกไปเท่าไรสั่งแทนทันทีเท่านั้น
- ตัวอย่าง: เก็บ Return-bend 5 อันเสมอ; เบิก 2 เหลือ 3 -> สั่ง 2 ทันที; On Hand 3 + On Order 2 = **5**
- เหมาะกับอะไหล่ประกันเตรียมพร้อม

## Order as Required (OAR) (book p.109-110)
- รายการอยู่ในทะเบียนสำรองคลัง (ไม่ใช่ของเข้าบัญชีค่าใช้จ่ายตรง) แต่สต็อกปกติ = 0 ซื้อเข้าเมื่อต้องการใช้ — ของหาง่าย lead time สั้น มีขายทั่วไป ไม่สำคัญต่อการผลิต/รอได้ เช่น สีทาเหล็ก/ไม้ ท่อประปา
- ตัวอย่าง: คงเหลือ 0 -> ต้องใช้สั่ง 20 -> เบิก 15 เหลือ 5 -> เบิก 5 เหลือ 0 -> ซื้อใหม่เมื่อมีความต้องการครั้งใหม่
- ข้อแนะนำ: ถ้าใช้ Reorder Report ให้ใส่ "OAR" ในคอลัมน์ OAR/Min เพื่อไม่ให้ระบบพิมพ์รายการสั่งซื้อเมื่อยังไม่ต้องใช้
- เหมาะกับ (1) พัสดุทั่วไปมีในตลาด จัดซื้อเร็ว (1 วัน/ชั่วโมง) และรอได้ (2) อะไหล่ที่วางแผนซ่อม/จัดหาล่วงหน้าได้ เช่น งานโครงการ ซ่อมบำรุงใหญ่ (บทที่ 4)

## ข้อสังเกต / ข้อผิดพลาดที่พบ
- คำนวณซ้ำทุกตัวอย่างแล้วถูกต้อง: ROP = 20×2 + 0.2×40 = 48; O₂ ROP = 40×0.5 + 0.1×20 = 22; สั่ง 120−22 = 98, 120−10 = 110; PRM 90−(25+30) = 35, 90−10 = 80; Order Up-to 3+2 = 5; OAR 20−15−5 = 0
- บทนี้ไม่มีตัวอย่างตัวเลข EOQ (ให้แค่สูตรและแบบฟอร์ม COP ว่าง); หน่วยต้องสอดคล้อง: A ต่อปี, I เป็นสัดส่วนต่อปี (เช่น 0.25 ไม่ใช่ 25)
- SS แบบ % ของ D×LT เป็นวิธีง่ายของผู้เขียนสำหรับ MRO ไม่ใช่สูตรเชิงสถิติ (z·σ) [ความรู้ทั่วไป]
- ข้อความ PRM "โดยมียอดจุดสั่งซื้ออยู่ตลอดเวลา" ขัดกับความหมาย fixed review cycle — น่าจะเป็น OCR/ถ้อยคำคลาดเคลื่อน (ควรเป็นรอบเวลาสั่งคงที่)
- ตารางสรุป p.110: คอลัมน์ Low Value Items ว่างทุกแถว ทั้งที่ข้อความว่า PRM เหมาะกับของราคาต่ำหมุนเร็ว -> อาจเป็น OCR วางเครื่องหมาย ✓ ผิดคอลัมน์ (PRM อาจควรอยู่ Low Value/Free Stock) [ไม่แน่ใจ ตรวจกับ PDF]
- OCR พิมพ์ "Hight Limi", "Planed" — คำผิดในต้นฉบับ/OCR ไม่กระทบเนื้อหา
- ไม่มีหัวข้อ ABC, EOQ ตัวเลข หรือ lead time variance เชิงสถิติในบทนี้
