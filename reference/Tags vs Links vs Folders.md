# Tags vs Links vs Folders

| กลไก | ใช้เมื่อ | ข้อจำกัด |
|---|---|---|
| Folder | สถานะ/บทบาทของโน้ต (Inbox, Project, Archive, raw) อยู่ได้ที่เดียว | ไม่ยืดหยุ่นกับหลายหัวข้อ |
| Link | ความสัมพันธ์ระหว่างความรู้ (เหตุผล, อ้างอิง) | ต้องเขียนเอง |
| Tag | หมวดข้าม folder สำหรับกรอง/ค้น (`type`-like facets) | tag เยอะเกินจะเละ ต้องมี taxonomy |

## แนวทาง

- Folder = lifecycle ([[PARA Method]])
- Link = ความรู้ ([[Zettelkasten and Atomic Notes]], [[Maps of Content]])
- Tag = facet สั้น ๆ ใช้ taxonomy ที่ล็อกใน [[SCHEMA]] ตัวพิมพ์เล็ก ขีดกลาง
- อย่า tag ซ้ำกับสิ่งที่ folder บอกอยู่แล้ว
- ถ้าไม่แน่ใจ ให้ใช้ link ก่อน
